# From Knowing to Doing (offline app)

An installable web app version of the dissertation dashboard. All data is stored on the phone (IndexedDB). No data is included in these files.

- index.html is generated by src/build.py from ../dashboard/dissertation-dashboard.html plus src/offline-shim.js. Rebuild after changing either, then bump VERSION in sw.js.
- Data moves in and out as JSON backup files (Files tab, Backup and import).
- Host on any HTTPS static host (GitHub Pages, Netlify). Service workers do not run from file://.
